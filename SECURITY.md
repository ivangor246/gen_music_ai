# Security Policy

## Supported Versions

Security fixes are provided for the most recent published release. Older releases may be asked to
upgrade before a report is investigated further.

## Reporting a Vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ivangor246/gen_music_ai/security/advisories/new)
for vulnerabilities that could affect users, local files, generated output, packaged binaries, or
the release process. Do not disclose a suspected vulnerability in a public issue.

Include the affected version and operating system, reproduction steps, expected impact, and any
known mitigations. Avoid attaching private files, credentials, or unrelated personal data. A
report may be closed as non-security-related if it only describes a functional bug without a
security impact.

For ordinary crashes, generation errors, and interface problems that do not expose or corrupt
data, use the [public bug report form](https://github.com/ivangor246/gen_music_ai/issues/new?template=bug_report.yml)
instead.
