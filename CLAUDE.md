This is a project for generating music using AI, with support for saving in MIDI format

## Guidelines
- Write as if you were an experienced Rust developer.
- If you’re unsure about anything, ask questions.
- **Write clean code**: small focused files/functions split by concern (follow the existing module layout below); no duplication — extract and reuse shared helpers instead of copy-pasting; no dead code; consistent naming with the surrounding code.
- Write comments in the code only when necessary (english comments only).
- Keep files/functions short. Chat in Russian.
- At the end of each change, write a short, one-line commit message. Use git flow style (for example - "feat: add user authentication").
- Always write code so that it can be reused, and reuse existing code.
- Don't guess—always double-check that the code works correctly.
